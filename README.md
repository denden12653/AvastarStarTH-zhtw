# AvatarStar 泰服繁體中文包

適用客戶端版本：**1.4.0.65874**。

## 下載

請到 [Releases](https://github.com/denden12653/AvastarStarTH-zhtw/releases)，下載 Assets 中的繁體中文 ZIP 壓縮包。

## 更新內容

- **通行證**：補齊每日／每週任務、獎勵說明、賽季文字及「購買高級通行證」按鈕的繁體中文。
- **情侶與婚禮**：補齊情侶邀請、戒指升級、婚禮預約、邀請卡、誓言及婚禮小禮等介面翻譯。
- **泰文／越南文顯示**：補入缺少字形，改善計分板、排行榜及玩家名稱顯示成方框的問題。
- **其他介面**：補齊戰績、公園、背包批次操作、配置方案、語音設定、兌換碼及武器外觀等文字。

本次為翻譯與顯示修正，遊戲玩法、數值、獎勵與價格維持原設定。

## 安裝

1. 確認客戶端版本為 1.4.0.65874，關閉遊戲與啟動器。
2. 備份遊戲原有的 `AvatarStar.pde` 與 `AvatarStar_zh_tw.pde`。
3. 將 ZIP 內的這兩個同名檔案，複製到 `client.exe` 所在資料夾，選擇取代。
4. 用記事本開啟自己的 `launch.ini`，在 `[Config]` 區段將語言設為 `Language=1028`，保留其他帳號與伺服器設定。
5. 儲存後重新啟動遊戲。

詳細步驟請參閱壓縮包內的安裝說明。不需要安裝額外執行環境或系統字型。

## 還原與相容性

關閉遊戲與啟動器，放回安裝前備份的原始資源檔，並恢復先前的語言設定即可。

本包目前僅驗證客戶端 1.4.0.65874；啟動器更新或修復可能覆蓋修改。其他版本需重新確認相容性。
